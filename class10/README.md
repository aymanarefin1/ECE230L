## Lab Questions

### What is difference between edge and level sensitive circuits?

Level sensitive circuits update their output continuously while the edge sensitives only update their output when their is a change from high to low or from low to high.

### Why is it important to declare initial state?

An FPGA's memory has no known value when it's programmed, so declaring an initial state ensures that the circuit start in a known state.

### What do edge sensitive circuits let us build?

They let us build synchronous systems like counters which level sensitive circuits can't do reliably because they would loop endlessly.
