## Summary

In this lab I used multiplexers to select one of 4 inputs and send it to a single output and demultiplexers to take that one input and send it to 4 outputs.

## Lab Questions

### In plain English describe the function and use of a multiplexer.

Taking multiple inputs and selecting one of them to send out as a single output.

### In plain English describe the function and use of a demultiplexer.

A demultiplexer does the opposite of a multiplexer where it takes one input and directs it to one of many outputs.

### What other uses might these circuits have? (Think Shannon’s)

A multiplexer can implement Boolean functions by using variables as select inputs and appropriate logic values as data inputs.
