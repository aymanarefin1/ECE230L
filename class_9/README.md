### What is the meaning of always @(\*) in a sensitivity block?

It means the block executes whenever any input signal used inside it changes.

### What importance is memory to digital circuits?

Memory is important in digital circuits because it allows circuits to store and retain data, remember previous states and perform sequential operations.
